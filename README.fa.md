> **یک کارخانه تولید نرم‌افزار کاملاً خودکار و هوشمند مبتنی بر هوش مصنوعی (OpenHands) و گیت‌هاب.**  
> تنها نیازمندی، فیچر یا باگ پروژه خود را در قالب یک فایل متنی (Spec) بنویسید؛ کارخانه آن را به فازهای وابسته (DAG) شکسته، ایشوهای گیت‌هاب را می‌سازد، کدنویسی و تست‌ها را انجام می‌دهد، باگ‌های CI را خودکار ترمیم کرده و پروژه را تا انتها تحویل می‌دهد!

## 🌟 ویژگی‌های برجسته کارخانه

- **شکست خودکار نیازمندی‌ها (Autonomous Requirements DAG):** نیازمندی کلی پروژه شما توسط برنامه‌ریز هوشمند به فازهای اجرایی مرتب و گراف وابستگی (DAG) تبدیل می‌شود.
- **ارکستریتور فازها (Event-Driven Phase Orchestration):** به محض اینکه PR فاز ۱ مرج شد، ارکستریتور قفل فاز بعدی را باز کرده و اجرای آن را کلید می‌زند.
- **حلقه خودکار عیب‌یابی و ترمیم PR (PR Auto-Healer):** اگر تست‌های CI فیل شوند یا در کد ریویو ایرادی مطرح شود، ایجنت به صورت خودکار لاگ خطا را بررسی کرده، کد را اصلاح و کامیت جدید ارسال می‌کند (تا ۳ مرحله تلاش مجدد).
- **کنسول و چت زنده ایجنت (Live Agent Console & HITL):** مشاهده زنده جریان تفکر، دستورات ترمینال ایجنت و امکان چت و ارسال دستور تعاملی در صورت نیاز به راهنمایی در حین کار.
- **پشتیبانی دوگانه (Local Agent Canvas & Cloud Engine):** امکان اجرا روی سخت‌افزار لوکال بدون هزینه یا اتصال به OpenHands Cloud برای کارهای تیمی سنگین.
- **راه‌اندازی Zero-Config با یک دستور:** نیازی به تنظیمات پیچیده نیست؛ یک اسکریپت تمام پیش‌نیازها، توکن‌ها و اسکیل‌ها را آماده می‌کند.
- **رابط کاربری دوزبانه (فارسی / انگلیسی) با تم لایت و دارک.**

## ⚡ راهنمای شروع سریع (در ۳۰ ثانیه!)

تنها کافیست مخزن را کلون کنید و دستور بوت‌استرپ را اجرا کنید:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/ali-ahadi1105/open-factory.git
cd open-factory

# ۲. اجرای خودکار کل استک
./factory up
```

### دستور `./factory up` به طور خودکار:
1. پیش‌نیازهای سیستمی (`Python >= 3.10`، `uv`، `gh`، `Node/npx` و `Docker`) را بررسی می‌کند.
2. احراز هویت گیت‌هاب شما را بدون نیاز به تایپ توکن (از طریق `gh CLI`) شناسایی می‌کند.
3. اسکیل اختصاصی **`ali-factory`** را مستقیماً به محیط OpenHands شما تزریق و فعال می‌کند.
4. موتور هوش مصنوعی OpenHands و داشبورد مدیریتی را بالا می‌آورد.
5. مرورگر شما را به صورت خودکار روی آدرس **`http://localhost:8080`** باز می‌کند.

## 🎮 دستورات خط فرمان (CLI)

| دستور | توضیح کارکرد |
|---|---|
| `./factory up` (یا `./factory`) | راه‌اندازی صفر تا صد سیستم: بررسی پیش‌نیازها، تزریق اسکیل، استارت انجین و باز کردن داشبورد |
| `./factory status` | نمایش وضعیت زنده داشبورد، موتور هوش مصنوعی، اکانت گیت‌هاب و وضعیت اسکیل |
| `./factory down` (یا `./factory stop`) | خاموش کردن تمیز تمام سرویس‌ها و آزادسازی پورت‌ها |
| `./factory skill sync` | همگام‌سازی و آپدیت اسکیل `ali-factory` در OpenHands |
| `./factory skill inject <repo-path>` | تزریق اسکیل مستقیماً داخل یک ریپازیتوری خاص (`.openhands/skills/ali-factory`) |
| `./factory logs [dashboard\|openhands]` | مشاهده یا دنبال کردن لاگ‌های زنده سرورها (`-f` برای مانیتورینگ زنده) |

## 🖥️ رابط کاربری و داشبورد مدیریتی

داشبورد وب روی پورت **8080** اجرا می‌شود و دارای امکانات زیر است:
- **سفارش پروژه جدید:** بارگذاری فایل Spec، انتخاب اکانت گیت‌هاب، انتخاب پابلیک/پرایوت بودن ریپو و راه‌اندازی با ۱ کلیک.
- **پایپ‌لاین زنده:** مشاهده وضعیت گراف، فاز فعال، درصد پیشرفت، وضعیت PRها، تست‌های CI و لاگ کامیت‌ها.
- **کنسول زنده ایجنت:** مشاهده تفکرات هوش مصنوعی، دستورات خط فرمان و خروجی تمیز ترمینال بدون پارازیت‌های ANSI.
- **چت تعاملی انسان در حلقه (Human-in-the-Loop):** ارسال پیام مستقیم یا دستورات تکمیلی به ایجنت در هنگام گیر کردن یا نیاز به تصمیم‌گیری.
- **تنظیمات چند اکانته گیت‌هاب:** افزودن و سوییچ آسان بین اکانت‌های کاری و شخصی با توکن‌های PAT.
- **تنظیمات موتور OpenHands:** سوییچ سریع میان موتور لوکال و OpenHands Cloud.
- **تم دوگانه و دوزبانه:** سوییچ میان تم دارک و لایت، و زبان‌های فارسی و انگلیسی.
